BAGIAN 6 - ALUR HIDUP APLIKASI (jalur eksekusi lengkap)
=======================================================

  A. BUILD TIME
     tsc/ngtsc  ->  NgCompiler.analyze (baca @Component)
                ->  compiler: HTML -> AST -> IR -> instruksi
                ->  emit: kelas + ɵcmp/ɵdir/ɵfac/ɵinj/ɵpipe

  B. BOOTSTRAP
     bootstrapApplication(App, {providers})
       -> createPlatform / PlatformRef
       -> createInjector (R3Injector) + APP_INITIALIZER
       -> ApplicationRef.bootstrap(App)
       -> ComponentFactory.create -> createLView/createTView
       -> renderView (fase creation) -> instruksi ɵɵelementStart dll
       -> ApplicationRef.tick pertama -> refreshView (fase update)

  C. RUNTIME (siklus perubahan)
     signal.set / markForCheck / event listener / setInput
       -> markViewDirty / markAncestorsForTraversal
       -> ChangeDetectionScheduler.notify -> dirtyFlags
       -> jadwal tick (rAF-race atau microtask)
       -> ApplicationRef._tick -> synchronize -> detectChangesInternal
       -> detectChangesInView -> refreshView (template, hooks, queries, host
          bindings, komponen anak, effects)
       -> afterRender hooks

  D. SSR + HIDRASI
     platform-server render -> annotateForHydration -> TransferState + ngh=*
       -> klien: withDomHydration -> instruksi mengklaim node yang ada
       -> event replay dari antrean jsaction
       -> cleanupDehydratedViews setelah stabil

BAGIAN 7 - KONVENSI KODE YANG BERULANG DI SELURUH REPO
======================================================
Memahami tujuh pola ini membuat sebagian besar kode langsung terbaca:

  1. `ɵɵnamaInstruksi`   API yang dipanggil kode hasil kompilasi (@codeGenApi).
     `ɵnama`             API internal yang tetap harus stabil antar paket.
  2. `ngDevMode`         blok yang dihapus total di build produksi. Sering
                         ditulis `ngDevMode && assert(...)`.
  3. Pola "enable*Impl"  fungsi indireksi + setter implementasi, dipakai agar
                         fitur opsional (hidrasi, i18n, animasi) tree-shakable.
  4. Save/restore state  `const prev = setX(v); try {...} finally { setX(prev); }`
                         dipakai untuk activeConsumer, currentInjector,
                         selectedIndex, injectImplementation.
  5. Prototipe + Object.create  node reaktif dan LView dibuat dari objek
                         prototipe agar bentuknya monomorfik (ramah JIT V8).
  6. Struktur data array LView/TData/opcodes adalah array berindeks konstanta,
                         bukan objek, demi ukuran bundel dan kecepatan.
  7. Komentar "PERF WARNING" / "do NOT change without benchmarking" menandai kode
                         yang bentuknya ditentukan hasil benchmark, bukan estetika.

BAGIAN 8 - KODE ERROR RUNTIME
=============================
Semua error runtime memakai `RuntimeError(RuntimeErrorCode.X, pesan)` dengan kode
numerik NGxxxx yang terdokumentasi di adev. Rentangnya:
  NG0000-NG0999  core (DI, CD, hidrasi, signal)
  NG1000-NG1999  compiler / template
  NG2000-NG2999  compiler-cli
  NG3000-NG3999  type-check template
  NG04xx         router
  NG05xx         hidrasi/SSR
  NG08xx         forms
Definisi lengkap: packages/core/src/errors.ts (enum RuntimeErrorCode).
